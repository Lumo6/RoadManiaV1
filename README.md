
# RoadMania

Bienvenue dans le projet **RoadMania** ! Ce dépôt contient le code source du jeu développé avec Unity

---

## Prérequis

Avant de commencer, assurez-vous d'avoir les outils suivants installés sur votre machine :

- **Unity 2022.3.4f1** (Téléchargez via Unity Hub)
- **Git** (https://git-scm.com/)

---

## Étapes pour cloner le projet

1. **Clonez le dépôt avec Git** :

   Ouvrez un terminal et exécutez la commande suivante :

   ```bash
   git clone https://github.com/<VotreNomDUtilisateur>/<NomDuDepot>.git
   ```
   
---

## Configuration du projet

1. **Ouvrez le projet Unity** :

   Une fois le dépôt cloné et les fichiers LFS téléchargés, cliquez sur `Add` puis `Add project from disk` et séléctionner le répertoire racine du projet.

---

## Conventions de développement

1. **Branches** :
   - La branche principale est `main`. Travaillez sur des branches spécifiques aux fonctionnalités, par exemple, `development/<votre-nom>` ou `development/<features>`.

2. **Commits** :
   - Utilisez des messages de commit clairs et descriptifs. Exemple : `Ajout du système de gestion des quêtes`.

3. **Pull Requests** :
   - Avant de fusionner dans `main`, soumettez une Pull Request pour révision.
